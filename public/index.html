💾 Záloha a Obnova dát systému

Tu môžete bezpečne stiahnuť kompletnú databázu (všetci zamestnanci, heslá, absencie a schválenia) alebo obnoviť dáta zo zálohy.

📥 1. Stiahnuť zálohu do PC / Mobilu

Vytvorí kompletný záložný JSON súbor so všetkými dátami.

📤 2. Obnoviť dáta zo zálohy

Nahrajte predtým stiahnutý súbor zálohy. Dáta sa ihneď bezpečne obnovia na serveri.

💡 Ako zabezpečiť 100% trvalé ukladanie na Render.com:
Bezplatný server Render má dočasný disk, ktorý sa pri reštarte vymaže. Váš prehliadač drží automatickú zálohu, no pre trvalé cloudové úložisko bez akejkoľvek straty dát pripojte bezplatnú PostgreSQL databázu (napr. z Neon.tech) zadaním premennej DATABASE_URL v nastaveniach Environment na Renderi.

☁️ Synchronizácia medzi mobilom a PC

ℹ️ Prečo sa fotka z mobilu neukázala na PC?

Keď je web nahratý iba ako statický ZIP súbor cez „Netlify Drop“, dáta ostávajú uložené len v pamäti toho konkrétneho telefónu. Aby mobil, počítač aj mobily zamestnancov zdieľali rovnaké dáta a fotky, musia byť pripojené do spoločného cloudu.

Spôsob 1 (Najjednoduchší – priamo na Netlify zadarmo):
  1. Nahrajte súbory z balíčka SP-asistent-cloud.zip do vášho GitHub repozitára YankeeAlpha/sp-asistent.
  2. Na Netlify (projekt sp-asistent) otvorte Site configuration → Build & deploy → Link repository a prepojte GitHub.
  3. Adresa sp-asistent.netlify.app zostane nezmenená a zapne sa vstavaný Netlify Blobs Cloud – bez ďalších účtov!
Spôsob 2 (Ak používate statický ZIP + vlastný Firebase Cloud):
